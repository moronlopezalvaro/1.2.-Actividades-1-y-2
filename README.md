# 1.2.-Actividades-1-y-2

## ¿Qué he hecho en este proyecto?

En este proyecto he estado experimentando con las diferentes formas de cargar e incluir código JavaScript en un documento HTML, para entender cómo afecta cada método al rendimiento y al renderizado de la página.

He creado un archivo `index.html` principal desde el que se puede acceder a varios escenarios de prueba:

- **Escenario A**: Script cargado directamente en el `<head>`. (Comprobando cómo bloquea el renderizado).
- **Escenario B**: Script cargado justo antes del cierre del `</body>`. (La forma clásica de mejorar la carga).
- **Escenario C**: Script con el atributo `async`.
- **Escenario D**: Script con el atributo `defer`.
- **Escenario E**: Script como `type="module"`.

Además, he adjuntado los PDFs con los informes y resultados de las actividades.
